## 🧠 Key Learning
A Stack follows the **LIFO (Last In, First Out)** principle.

The main operations are:
- `push()` → insert an element
- `pop()` → remove the top element
- `peek()` → access the top element

Stack is commonly used in:
- Function calls
- Recursion
- Undo operations
- Expression evaluation
- Parentheses matching
- String reversal

## ⏱️ Time Complexity
- Push: O(1)
- Pop: O(1)
- Peek: O(1)
- Stack length: O(1) using built-in length
- Finding minimum: O(n)
- Reversing a stack: O(n)
- Reversing a string using stack: O(n)
