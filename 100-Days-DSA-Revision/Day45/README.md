# Day 45 – Combination Sum

## Overview

Day 45 of my **100 Days DSA Revision Journey** focused on solving **Combination Sum** problems using **Backtracking**. These problems strengthened my understanding of recursive decision-making, pruning unnecessary paths, and handling duplicate elements while generating valid combinations.

## Programs Implemented

* Combination Sum I
* Combination Sum II

## Concepts Practiced

* Backtracking
* Recursion
* Choose → Explore → Undo pattern
* Pruning invalid paths
* Base cases
* Handling duplicate elements
* Generating unique combinations
* Recursive tree traversal

## Key Learning Outcomes

* Learned how to build combinations recursively.
* Understood when to reuse an element and when to move to the next index.
* Practiced avoiding duplicate combinations by skipping repeated elements.
* Improved confidence in solving recursive and backtracking interview problems.
